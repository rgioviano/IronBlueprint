# Steps
1. Confirm this ask is a Minute-style email (one idea, series-tagged value note). If it is any other email type, stop and use that type's own skill or lane instead.
2. Read the guide first: `/workspace/books/sales/hormozi-email-craft-guide.md` (use the Read tool on that absolute path). Use only the in-scope Minute pattern and Minute skeleton. Ignore the archive patterns unless Ryne explicitly asked for that type.
3. Pick a subject-line pattern that fits Minute (series tag + short hook). Keep it 2 to 7 words.
4. Build the body from the Minute fill-in skeleton: hook, problem, one fix, why it matters, one action, soft CTA, short sign-off, light PS. Value before ask. One soft CTA.
5. Apply brand notes: Achieve = coach voice, evaluation CTA, skill/confidence/readiness only; IronBlueprint = AI is the tool, coach expertise is the product.
6. Check hard rules: no invented prices, testimonials, results, seat counts, or dates (use [FILL]); no em dashes in Achieve drafts; draft only, never send or schedule.
7. Ownership: Marketing decides it is a Minute email and owns structure; Copywriter may polish lines; Sales owns nurture/close/pricing.
